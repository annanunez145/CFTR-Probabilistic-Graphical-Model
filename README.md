# CFTR-Probabilistic-Graphical-Model
Python implementation of a probabilistic graphical model for CFTR protein interaction data.

# Probabilistic Graphical Models for CFTR Protein Interaction Networks

This repository contains the Python code used in the thesis "Probabilistic Graphical Models for CFTR Protein Interaction Networks."

The code includes:

- BioGRID data processing
- Protein interaction data preparation
- Publication-level dataset construction
- Bayesian network structure learning
- Bayesian parameter estimation using BDeu
- Probabilistic inference using variable elimination
- Bayesian Information Criterion (BIC) model assessment

## Software

The analysis was conducted using Python and the `pgmpy` probabilistic modeling package.

## Thesis

This repository contains the computational implementation used to produce the results presented in the thesis.
